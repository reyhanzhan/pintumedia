# Panduan akses katalog dan API PintuMedia

Diperiksa 22 September 2026. Daftar mengikuti 56 nama di picker referensi.

## Apa yang perlu diperoleh

Daftar 56 platform di website sudah tersedia. Koneksi API/video dari platform-platform itu belum aktif. Riset ini menemukan kontak kerja sama atau dukungan; belum memverifikasi akses API streaming publik untuk seluruh daftar. Kontak email bukan API key dan tidak menjamin permohonan diterima.

Yang diajukan adalah izin menayangkan katalog di website PintuMedia, wilayah Indonesia, dengan lima episode gratis lalu paket berbayar dan referral. Tanyakan apakah mereka menawarkan API, SDK/player embed, feed katalog, atau pengiriman file video berlisensi. Jika mereka hanya menerima unggahan karya ke platformnya, jelaskan bahwa kebutuhan PintuMedia adalah mendapatkan katalog untuk ditayangkan di website sendiri.

## Urutan mengajukan akses

1. Siapkan nama pengelola/badan usaha yang sebenarnya, domain, email kontak, deskripsi PintuMedia, target Indonesia, dan perkiraan pengguna yang jujur.
2. Mulai dari kontak berlabel **Bisnis** di tabel. Untuk **Dukungan**, minta pesan diteruskan ke tim licensing/distribution/partnership. Alamat yang terlihat seperti Gmail dicantumkan hanya jika tercantum di situs atau listing aplikasi pengembang.
3. Untuk **Kandidat** dan **Identitas perlu dipastikan**, cocokkan URL aplikasi, package ID, nama pengembang, ikon, dan domain dari platform referensi. Nama sama tidak cukup. Untuk baris yang belum terverifikasi, minta identitas ini dari pengelola referensi; belum ada kontak yang dapat saya pastikan.
4. Ajukan pertanyaan tentang katalog yang tersedia, harga/minimum kontrak, wilayah, hak subtitle Indonesia/Inggris, penayangan ulang di domain sendiri, lima episode gratis, paket berbayar, serta program referral.
5. Jika permohonan diterima, minta dokumentasi resmi, kredensial uji, contoh respons katalog/episode, batas penggunaan, masa berlaku URL video, DRM/player, pembaruan katalog, dan dukungan teknis.
6. Integrasikan satu provider yang sudah memberi akses terlebih dahulu. Uji satu serial lengkap dan hak akses episode sebelum menambah provider berikutnya. Simpan secret API di konfigurasi server, bukan di GitHub atau kode browser.

## QRIS dan pembukaan episode

Logo dan QRIS yang dipasang berasal dari file yang Anda kirim. QRIS menampilkan merchant TOKOSWAG dan NMID ID1025369150350. Gambar disalin tanpa perubahan isi. Harga paket memakai nilai yang sudah ada di proyek: serial Rp25.000, bulanan Rp39.000, tujuh hari Rp19.000; ini belum merupakan harga produksi yang disetujui provider.

Menempel gambar QR tidak memberi website notifikasi pembayaran. Untuk memakai QR ini secara manual, diperlukan pesanan, akun pembeli, pencocokan pembayaran di dashboard merchant, dan pemberian akses oleh admin. Alur manual itu belum dibuat. Untuk otomatis, minta API/notifikasi transaksi dari penyedia QRIS merchant Anda, atau buat QRIS per pesanan melalui payment gateway yang mendukungnya. QR dari gateway lain tidak otomatis terhubung ke gambar QRIS yang sudah ada.

Midtrans mendokumentasikan notifikasi pembayaran, pemeriksaan signature, pencocokan order_id/nominal, dan status settlement. Server perlu memverifikasi status sebelum memberikan akses dan komisi; notifikasi berulang tidak boleh menggandakan akses atau komisi. [Dokumentasi notifikasi Midtrans](https://docs.midtrans.com/docs/https-notification-webhooks), [API QRIS](https://docs.midtrans.com/reference/qris).

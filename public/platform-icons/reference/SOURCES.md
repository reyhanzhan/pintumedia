# Ikon pemilih platform

56 ikon dalam folder ini berasal dari pemilih platform publik https://nunodrama.my.id/ yang diperiksa pada 22 September 2026, sesuai referensi pengguna. Nama file dipertahankan dari URL sumber: https://nunodrama.my.id/<nama-file>.

Nama dan urutan lengkap ada di lib/platforms.ts. File lokal digunakan agar ikon tidak bergantung pada hotlink ke website referensi.

Daftar provider tidak menandakan koneksi API video aktif. Nama dan logo tetap milik pemilik masing-masing.
